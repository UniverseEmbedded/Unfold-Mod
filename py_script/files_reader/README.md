# 增强版文件处理脚本使用说明

## 功能概览

这两个增强版脚本支持以下功能：

1. **从 ./files/ 目录选择txt文件作为路径列表**
2. **文件夹递归处理和gitignore式排除功能**
3. **.env配置项目根目录**

## 安装依赖

```bash
pip install python-dotenv
```

## 配置文件

### .env 文件配置

在脚本同目录下创建 `.env` 文件：

```env
# 项目根目录，用于处理相对路径
PROJECT_ROOT=/path/to/your/project
```

如果不设置，默认使用当前目录作为项目根目录。

### .gitignore 排除规则

脚本会自动读取 `.gitignore` 文件中的排除规则，也有内置的默认排除模式：

```gitignore
# 内置默认排除模式
.git/**
.venv/**
__pycache__/**
*.pyc
*.pyo
*.pyd
.DS_Store
Thumbs.db
*.log
temp/**
tmp/**
node_modules/**
.env
*.bak
*.swp
*.tmp
```

### files 目录结构

创建 `./files/` 目录来存放路径列表文件：

```
project/
├── enhanced_read_files_to_stdout.py
├── enhanced_save_files_to_temp.py
├── .env
├── .gitignore
└── files/
    ├── project_files.txt
    ├── source_code.txt
    └── documentation.txt
```

## 使用方法

### 1. enhanced_read_files_to_stdout.py

将文件内容输出到控制台：

```bash
python enhanced_read_files_to_stdout.py
```

运行后会：
1. 显示 `./files/` 目录下的所有txt文件供选择
2. 如果选择了文件，会读取其中的路径列表
3. 如果选择手动输入，会等待从stdin输入路径
4. 支持文件夹路径（会递归处理所有文件）
5. 自动排除匹配规则的文件

### 2. enhanced_save_files_to_temp.py

将文件内容聚合保存到 `./temp/` 目录：

```bash
python enhanced_save_files_to_temp.py
```

生成的文件包含：
- 完整的处理报告
- 原始输入路径列表
- 实际处理的文件列表
- 每个文件的完整内容

## 路径列表文件格式

在 `./files/` 目录下的txt文件中，每行一个路径：

```
# project_files.txt 示例
src/
docs/main.md
config/settings.py
README.md
/absolute/path/to/file.txt
```

支持：
- 绝对路径
- 相对路径（相对于PROJECT_ROOT）
- 文件路径
- 文件夹路径（会递归处理）

## 排除规则语法

支持以下gitignore风格的模式：

```gitignore
# 注释行以 # 开头

# 精确匹配文件名
filename.txt

# 通配符匹配
*.log
temp*

# 目录匹配（以/结尾）
build/
dist/

# 递归匹配（**）
logs/**
**/cache/**

# 路径匹配
src/temp/
```

## 示例使用场景

### 场景1: 处理项目源代码
1. 在 `files/source_code.txt` 中列出需要处理的源码目录
2. 运行脚本选择该文件
3. 自动排除编译文件、缓存等

### 场景2: 文档聚合
1. 在 `files/documentation.txt` 中列出文档路径
2. 使用save脚本生成聚合文档

### 场景3: 快速文件查看
1. 直接使用手动输入模式
2. 粘贴文件路径进行快速查看

## 错误处理

脚本会优雅处理各种错误情况：
- 文件不存在：显示警告并跳过
- 读取失败：显示错误信息并继续处理其他文件
- 目录不存在：自动创建或跳过
- 编码问题：使用UTF-8并替换无效字符

## 注意事项

1. **相对路径处理**：所有相对路径都相对于.env中设置的PROJECT_ROOT
2. **排除规则优先级**：.gitignore规则会添加到内置规则中
3. **文件编码**：统一使用UTF-8编码，遇到问题会自动替换
4. **内存使用**：大文件或大量文件可能占用较多内存
5. **权限问题**：确保脚本有读取文件和创建temp目录的权限
